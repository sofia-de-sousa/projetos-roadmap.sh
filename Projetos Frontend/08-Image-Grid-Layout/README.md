# Image Grid Layout

## Objetivo

Recriar um layout de imagens responsivo utilizando HTML e CSS, aplicado conceitos de CSS Grid, posicionamento de elementos, alinhamento e espaçamento entre imagens para adaptar a disposição a diferentes tamanhos de tela enquanto mantém um design visualmente apelativo.
